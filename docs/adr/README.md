# Architecture Decision Records

Small, append-only records of architecture and one-way-door decisions. One decision per
file, named `NNNN-short-slug.md`. Add every new ADR to the index below, and keep every
cross-reference (Supersedes / Superseded by / Related) pointing at a file that exists.

## Template

```md
# NNNN. <Title>

- Status: Proposed | Accepted | Superseded by NNNN
- Date: <YYYY-MM-DD>

## Context
What forces are at play (constraints, requirements, the problem)?

## Decision
The decision, stated plainly.

## Consequences
What becomes easier or harder as a result. Include the reversible vs one-way-door call.

## Alternatives considered
The options not chosen, and why. (Record the not-chosen option so it is not re-litigated.)
```
